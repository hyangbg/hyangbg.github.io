Privacy policy

Gym Health is a private, personal-use tool used only by its owner, Haochen Yang. This policy describes how that tool handles Google Health data. Last updated October 18, 2026.

What data is accessed

With the owner's explicit consent via Google OAuth, Gym Health requests read-only Google Health API scopes. The data that may be read is limited to:

  • Activity and fitness: steps, distance, calories, active zone minutes, and exercise sessions.
  • Health metrics and measurements: weight, body fat, heart rate, resting heart rate, and heart rate variability.
  • Sleep.

How data is used

Data is used only for the owner's personal workout planning and progress tracking. Gym Health never writes to or modifies Google Health data.

Sharing

Data is not sold, shared, or disclosed to any third party. It is not used for advertising.

Storage and security

OAuth tokens and data are stored privately on the owner's own computer. Access is restricted to the owner.

Deletion and revocation

Access can be revoked at any time at https://myaccount.google.com/permissions. Local data can be deleted at any time.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
